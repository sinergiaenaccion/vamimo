# VAMIMO

Plataforma de servicios para mascotas que ayuda a encontrar y contactar prestadores, consultar sus servicios y organizar solicitudes. La identidad y los datos de VAMIMO deben mantenerse separados de Emprenlazo, aunque se puedan reutilizar patrones técnicos.

## Estado

Repositorio con definición inicial de producto. La aplicación todavía no está implementada ni validada en producción.

## Alcance propuesto para el MVP

1. Página de inicio con categorías de servicios para mascotas.
2. Directorio de prestadores con filtros por zona aproximada y tipo de servicio.
3. Fichas de prestadores con descripción, fotos, horarios y formas de contacto.
4. Perfil de prestador y formulario de alta sujeto a revisión.
5. Categorías iniciales a validar: paseo, cuidado/guardería, peluquería, veterinaria y adiestramiento.
6. Solicitud de contacto o servicio sin pagos integrados en la primera versión.
7. Reporte de ficha y panel de administración para moderación.

## Seguridad y confianza

- No presentar profesionales como verificados hasta que exista un proceso comprobable.
- No publicar domicilios particulares ni ubicación exacta sin consentimiento.
- Evitar almacenar información clínica innecesaria.
- Incluir condiciones de uso, privacidad y canal de reportes antes del lanzamiento público.

## Reutilización técnica

Emprenlazo puede servir como referencia para directorios, fichas, perfiles de prestadores, horarios y políticas de acceso. No se deben mezclar marcas, cuentas, contactos, contenido ni datos entre proyectos.
